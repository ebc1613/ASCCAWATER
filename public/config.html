Tank Size & Water Usage

Loading

There is no flow meter on this system. Gallons used are estimated from how much the tank level drops, plus how long the pump runs. Only the tank's inside diameter is needed — usage comes from changes in level, so the 1 ft offset between this sensor and the tank's physical gauge cancels out.

Water drawn while the pump is filling is hidden by the incoming water, so the pump's flow rate is needed to add it back. Left automatic, it is inferred from how fast the tank actually rose during past fills. The manual value is used when automatic detection has nothing to go on yet.

Detecting hardware

Just plugged the relay in? Press Refresh Port List - newly connected USB devices show up here without restarting anything.

Cheap relay boards often have no serial number, so their port path can change every time they disconnect and reconnect. Locking to the selected device's vendor/product ID finds it by hardware identity instead of a fixed path, so reconnects keep working automatically. The port path above is kept as a fallback if no match is found.
