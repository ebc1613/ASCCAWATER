Detecting hardware

Cheap relay boards often have no serial number, so their port path can change every time they disconnect and reconnect. Locking to the selected device's vendor/product ID finds it by hardware identity instead of a fixed path, so reconnects keep working automatically. The port path above is kept as a fallback if no match is found.

Changing this requires an app restart to take effect.
